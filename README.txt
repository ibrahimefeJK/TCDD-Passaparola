TCDD PASSAPAROLA YARIŞMASI

1. PASSAPAROLA_BASLAT dosyasına çift tıklayın (veya index.html dosyasını açın).
2. Gerekirse TAM EKRAN'a basın.
3. BAŞLAT'a basıp yarışmacı adını girin.
4. Sorular için YÖNETİM bölümüne girin (varsayılan PIN: 1234).

USB ile veri taşımak için: YÖNETİM > YEDEKLEME > YEDEĞİ İNDİR.
Başka bilgisayarda YEDEĞİ GERİ YÜKLE ile JSON dosyasını seçin.
Uygulama internet, kurulum, sunucu veya yönetici izni gerektirmez.
